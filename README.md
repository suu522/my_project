2.专业学习《深度学习》（花书）读书笔记

作者：Ian Goodfellow, Yoshua Bengio, Aaron Courville  
定位：深度学习领域百科全书，不适合零基础入门，建议配合实践课程阅读。

第一部分：数学与机器学习基础（第1–5章）

1. 核心数学工具
- 线性代数：标量、向量、矩阵、张量；矩阵乘法、范数、特征分解、奇异值分解（SVD）。
- 概率与信息论：随机变量、常用分布（高斯、伯努利）、期望、方差；熵 H(P)= -∑ P(x) log P(x)、KL散度 D_KL(P||Q)= E_{x~P}[log(P/Q)]、交叉熵。
- 数值计算：梯度下降、Jacobian矩阵、Hessian矩阵；上溢/下溢、病态条件；拉格朗日乘子法。

2. 机器学习基础
- 监督/无监督/强化学习的定义。
- 泛化：欠拟合（高偏差）vs 过拟合（高方差）。
- 模型容量、正则化、超参数调优。

第二部分：深度网络核心方法（第6–12章）

3. 深度前馈网络（MLP）
- 结构：输入层 → 隐藏层（多层）→ 输出层。
- 激活函数：ReLU (max(0,x))、sigmoid、tanh；非线性是关键。
- 万能逼近定理：足够神经元可逼近任意连续函数。
- 反向传播：链式法则计算梯度。

4. 正则化（防过拟合）
- L2正则化（权值衰减）、L1正则化（稀疏）。
- 数据集增强、早停、Dropout（随机失活神经元）。
- 对抗训练。

5. 深度模型优化
- 梯度消失/爆炸、参数初始化（Xavier）、学习率调度。
- 优化器：SGD（带动量）、AdaGrad、Adam。

6. 卷积网络（CNN）
- 局部连接 + 权值共享，适合图像等网格数据。
- 卷积层、池化层（降采样）。

7. 循环网络（RNN）
- 处理序列数据（文本、时间序列）。
- LSTM、GRU（门控机制缓解梯度消失）。

8. 实践方法论
- 性能评估、超参数调优（网格/随机搜索）、分布式训练。

第三部分：前沿专题（第13–20章）

- 自编码器：无监督特征学习，变分自编码器（VAE）。
- 表示学习：分布式表示。
- 生成对抗网络（GAN）：生成器 G 与判别器 D 博弈。
- 注意力机制与Transformer：目前大模型基础（自注意力、位置编码）。

3.遇到的问题及解决方法
问题1：EEG 信号质量评估指标不够鲁棒
现象：部分用户 EEG 数据经过预处理后，信噪比仍然较低，但实际信号可用。若仅依赖 SNR 判断，会过度降低 EEG 权重。

原因：SNR 对基线漂移敏感，且无法反映伪迹的类型和可恢复性。

解决方法：

引入第二个特征 —— 独立成分分析（ICA）中伪迹成分的占比。伪迹成分比例越低，质量越高。

最终质量评分 Q = 0.6 * Q_SNR + 0.4 * Q_ICA，其中 Q_ICA = 1 - (伪迹成分数 / 总成分数)。

测试表明，组合指标在低质量样本上的判准率提高了 15%。
4.实践总结
本周是毕业设计进入优化与收尾阶段的关键一周。我主要围绕双模态融合模型的自适应权重机制展开了深入工作，同时兼顾了专业学习。通过这一周的实践，我有以下几点深刻体会：

首先，在毕设推进方面，我意识到“一个真正可落地的模型”不仅要追求公开数据集上的准确率，更要考虑实际应用中数据的多样性（例如用户配合度不同导致的信号质量差异）。自适应权重策略虽然增加了算法的复杂度，但它显著提升了系统在非理想条件下的鲁棒性。实验中，自采数据中低质量 EEG 样本的准确率从 89.2% 提升到 92.3%，这说明针对实际痛点进行优化，比单纯调高基准线更有价值。此外，前端分片导入和离线缓存的改进，虽然属于工程细节，但直接决定了用户的体验——如果移动端一导入大数据就卡顿，再好的模型也无法推广。

其次，在专业学习上，我尝试将 Transformer 的自注意力机制引入 EEG 分析，虽然只是预实验，但让我看到了未来可能的改进方向——注意力机制可以自适应地关注不同通道、不同时间段的信号特征，或许能进一步提升对轻度认知障碍的识别能力。这为我论文的“未来展望”部分提供了实质性的内容。

本周的实践也暴露出我的时间管理仍可优化：前期花在自适应权重调参上的时间过多，导致论文第五章的写作压缩到了周末。后续我将以周为单位设定明确的“交付物”，例如周末必须完成某一节定稿。总体而言，本周的工作让我对节奏更加适应，我也有信心在接下来的两周内完成论文终稿。
