# 学习笔记：Git 和 Gitee/GitHub 实践

## 学习资料来源
- [Pro Git Book](https://git-scm.com/book/en/v2)
- [GitHub 官方文档](https://docs.github.com/)
- [Gitee 官方文档](https://gitee.com/help)

## 实践流程
1. 安装并配置 Git。
2. 创建本地仓库并初始化。
3. 注册 Gitee/GitHub 账号，创建远程仓库。
4. 将本地代码推送到远程仓库。
5. 提交代码并观察变更。

## 遇到的困难及解决方法
- **问题**：无法推送代码到远程仓库。
  - **解决方法**：检查 SSH 密钥是否正确配置，或者使用 HTTPS 方式推送。
- **问题**：提交历史显示为空。
  - **解决方法**：确保本地仓库中有文件，并正确执行 `git add` 和 `git commit`。

## 心得
通过本次实践，我掌握了 Git 和 Gitee/GitHub 的基本操作，包括代码管理、版本控制和远程仓库的使用。这些技能将为我未来的项目开发提供有力支持。
